# Brief: Telegram Mini App — Каталог оптовой продажи тканей

> Версия 1.0 (MVP) · Русский язык · Нативный стиль Telegram · Мобильный телефон

---

## Концепция одной фразой

Оптовый покупатель открывает Telegram-бота → видит каталог тканей с фото,
параметрами и живыми остатками → добавляет нужные позиции к заявке →
отправляет заявку менеджеру. Без сайта, без звонков, без PDF.

---

## Дизайн-система

```
Цвета (CSS-переменные Telegram — автоматически светлая/тёмная тема):
  Фон:            var(--tg-theme-bg-color)
  Текст:          var(--tg-theme-text-color)
  Подсказки:      var(--tg-theme-hint-color)
  Ссылки:         var(--tg-theme-link-color)
  Кнопка:         var(--tg-theme-button-color)
  Текст кнопки:   var(--tg-theme-button-text-color)
  Вторичный фон:  var(--tg-theme-secondary-bg-color)

Акцентные цвета (поверх темы):
  Цена:           #C0392B  (красный — выделяет оптовую цену)
  В наличии:      #27AE60  (зелёный)
  Мало осталось:  #E67E22  (оранжевый)
  Нет в наличии:  #95A5A6  (серый)

Шрифт: системный (-apple-system / Roboto) — не загружаем внешние
Скругления: 12px для карточек, 8px для бейджей, 50px для кнопок-чипов
Тени: нет (нативный стиль Telegram не использует тени)
Кнопки: минимум 48px высота, полная ширина или minWidth 120px
```

## Навигация (структура приложения)

```
┌─────────────────────────────────┐
│  [Шапка Telegram — BackButton]  │
├─────────────────────────────────┤
│                                 │
│         КОНТЕНТ ЭКРАНА          │
│                                 │
├─────────────────────────────────┤
│   [MainButton Telegram — CTA]   │  ← фиксированная кнопка снизу
├─────────────────────────────────┤
│  Каталог │ Поиск │ 🛒(3) │ Профиль  │  ← Tab Bar
└─────────────────────────────────┘
```

**Tab Bar (4 вкладки):**
- Каталог — иконка сетки
- Поиск — иконка лупы
- Корзина — иконка корзины + бейдж с количеством позиций
- Профиль — иконка человека

**BackButton** — нативная кнопка Telegram, показывается на всех экранах кроме корневого Каталога.

**MainButton** — фиксированная кнопка Telegram внизу, текст меняется в зависимости от экрана.

### Экран 1: Каталог (корневой экран)

**Что видит пользователь:**
Сетка карточек тканей в 2 колонки. Сверху — горизонтальный скролл категорий.

```
┌─────────────────────────────────┐
│  Ткани оптом        [🔍] [⚙️]  │  ← заголовок + поиск + фильтр
├─────────────────────────────────┤
│ [Все] [Трикотаж] [Костюмные]   │  ← горизонтальный скролл категорий
│ [Подкладочные] [Джинсовые] ──► │
├──────────────┬──────────────────┤
│ ┌──────────┐ │ ┌──────────────┐ │
│ │  [фото]  │ │ │    [фото]    │ │
│ │          │ │ │              │ │
│ │ Штапель  │ │ │  Трикотаж    │ │
│ │ вискоза  │ │ │  хлопок 95%  │ │
│ │ 100%     │ │ │              │ │
│ │ 140см    │ │ │ 180см        │ │
│ │ 380 ₽/м  │ │ │ 520 ₽/м      │ │
│ │ 142 м ✓  │ │ │ 80 м ⚠       │ │
│ └──────────┘ │ └──────────────┘ │
│ ┌──────────┐ │ ┌──────────────┐ │
│ │  [фото]  │ │ │    [фото]    │ │
│    ...               ...        │
└─────────────────────────────────┘
│        [Показать фильтры]       │  ← MainButton (если фильтры не применены)
└─────────────────────────────────┘
```

**Элементы:**
- Заголовок "Ткани оптом" (20px, bold)
- Иконка поиска 🔍 → переход на Поиск
- Иконка фильтра ⚙️ → открывает Фильтры (bottom sheet)
- Горизонтальный скролл категорий — чипы 36px высота, активный выделен цветом кнопки TG
- Карточки товаров в сетке 2 колонки:
  - Фото (aspect-ratio 3:4, object-fit: cover, lazy loading)
  - Название ткани (14px, bold, максимум 2 строки)
  - Состав (12px, secondary color)
  - Ширина полотна (12px, secondary)
  - Цена за метр (16px, bold, акцентный красный)
  - Остаток: зелёный "142 м ✓" / оранжевый "80 м ⚠" / серый "Нет ✕"
- Счётчик результатов "Показано: 48 позиций" (12px, hint color)

**Действия:**
- Тап на карточку → Карточка товара
- Тап на категорию → фильтрует список (без перезагрузки)
- Тап на 🔍 → Поиск
- Тап на ⚙️ → Фильтры (bottom sheet)
- Скролл вниз → пагинация (подгружает следующие 20 позиций)

**MainButton:** скрыта на этом экране (или "Показать фильтры" если фильтры применены)

**Переходы:**
- → Карточка товара (тап на карточку)
- → Поиск (тап на 🔍)
- → Фильтры bottom sheet (тап на ⚙️)

└─────────────────────────────────┘
```

**Элементы:**
- ← BackButton (нативный Telegram)
- ♡ Избранное (иконка в правом верхнем углу, 44×44px touch area)
- Галерея фото (swiper, соотношение 4:3, pinch-to-zoom, dots внизу)
- Название ткани (18px, bold)
- Артикул (12px, hint color)
- Чипы параметров: состав / ширина / плотность (некликабельные, только информация)
- Свотчи цветов: круги 36×36px + рамка на выбранном. Тап → меняет фото в галерее
- Цена за метр (24px, bold, красный)
- Минимальный заказ и кратность (12px, hint)
- Раскрывающаяся секция "Скидки по объёму" → таблица цен по объёму
- Остаток с цветовой индикацией (зелёный / оранжевый / серый)
- Счётчик метража: кнопки − и + (48×48px), поле с прямым вводом числа
- Автокалькулятор: "Итого: X ₽" — пересчитывается при изменении метража
- Кнопка "Запросить образец" (link color, 48px touch area)

**Действия:**
- Свайп по галерее → переключает фото
- Pinch-to-zoom на фото → зум
- Тап на свотч цвета → меняет фото, обновляет выбор
- Тап "▼ Скидки по объёму" → раскрывает таблицу цен
- Нажатие − / + → изменяет метраж с шагом кратности
- Прямой ввод в поле метража → принимает и округляет до кратного
- Тап ♡ → добавляет в избранное (haptic feedback)
- Тап "Запросить образец" → переход на экран запроса образца
- Тап MainButton "Добавить к заявке" → добавляет в корзину (haptic feedback), кнопка меняется на "В заявке ✓"

**MainButton:**
- Пустая корзина: "Добавить к заявке · 50 м"
- Уже добавлен: "В заявке ✓ · Перейти к заявке"

**Переходы:**
- ← → Каталог (BackButton)
- ♡ → без перехода (toggle)
- "Запросить образец" → Запрос образца (bottom sheet)
- MainButton "Добавить к заявке" → без перехода (toast-уведомление)
- MainButton "Перейти к заявке" → Корзина

## Что НЕ будет в версии 1

| Функция | Почему отложено |
|---|---|
| Верификация B2B (ИНН, статус) | MVP показывает цены всем, верификация — v2 |
| Оплата онлайн (Telegram Payments) | Оптовик платит по счёту, не картой |
| Сравнение товаров рядом | Усложняет UI, нет в MVP |
| Калькулятор "метры → единицы изделий" | v2, требует логики по видам изделий |
| Уведомления о поступлении | Требует отдельной системы подписок |
| Персональные подборки от менеджера | v2, требует CRM-интеграции |
| Генерация PDF заявки | v2, менеджер формирует сам |
| Сертификаты на ткани в карточке | v2, нужна загрузка документов |
| Интеграция с 1С/складской системой | v2, через API или ручное обновление |
| Регистрация / логин / пароль | Авторизация только через Telegram ID |
| Несколько языков | Только русский |
| Тёмная тема ручная | Автоматически через CSS-переменные Telegram |
| Чат с менеджером внутри Mini App | Используется нативный TG чат |
| Мультивалютность | Только рубли |

## Технический стек MVP

```
Frontend:   React 18 + TypeScript + Vite
Стили:      CSS Modules + CSS-переменные Telegram
State:      Zustand (корзина, фильтры)
Router:     React Router v6 (hash mode)
TG SDK:     @twa-dev/sdk
Галерея:    Swiper.js (только модули Zoom + Navigation)
Иконки:     react-icons или SVG спрайт
Сеть:       axios + react-query

Backend MVP (минимальный):
  - Node.js / Express (или Cloudflare Workers)
  - Google Sheets API для хранения заявок
  - Telegram Bot API для уведомления менеджера
  - JSON-файл или Notion API как база каталога

Хостинг:    Vercel (фронт) или Cloudflare Pages
Бот:        @BotFather → Webhook → сервер

Изображения:
  Thumb 200×200 WebP → список каталога
  Medium 800×800 WebP → карточка товара
  CDN: Cloudflare R2 или любой S3-совместимый
```

## Критические правила реализации

1. `WebApp.ready()` и `WebApp.expand()` — первые строки при инициализации
2. `padding-bottom: calc(60px + env(safe-area-inset-bottom))` — на всех экранах
3. BackButton — один обработчик в корневом Layout, не в каждом компоненте
4. MainButton — всегда cleanup `offClick` в `return` useEffect
5. Никаких `alert()` / `confirm()` — только `WebApp.showPopup()` / `showConfirm()`
6. HapticFeedback на: добавление в корзину, удаление, отправку заявки, ошибку
7. Бандл < 200KB gzipped — проверять `vite build --report` перед релизом
8. Все кнопки и интерактивные элементы — минимум 44×44px touch area
9. Lazy loading на все изображения кроме первых 4 карточек каталога
10. Фильтры сохранять в CloudStorage — не сбрасывать при возврате назад
```
