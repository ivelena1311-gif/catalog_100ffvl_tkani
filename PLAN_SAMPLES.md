# Идеи и план развития: Запрос образцов

> Статус: [ ] — не реализовано, [x] — выполнено

---

## Идея 1: Выбор образцов без привязки к цвету

Клиент добавляет конкретные ткани (SKU) в корзину образцов — без выбора цвета. Например: Севиль, Прага, Замша. Любое количество разных позиций.

### Задачи

- [ ] БД — сделать `color_id` nullable в `sample_request_items`
- [ ] API `api/samples.js` — убрать требование color_id
- [ ] Frontend — убрать шаг выбора цвета из флоу образцов
- [ ] Frontend — кнопка «Добавить образец» на карточке ткани
- [ ] Frontend — корзина образцов: список выбранных тканей с возможностью удалить
- [ ] Admin — в таблице образцов показывать без колонки «цвет» (или «—»)
- [ ] Telegram-уведомление — формат без цвета:
  ```
  📦 Заявка на образцы #42
  👤 Иван Иванов (@ivan)
  • Севиль (id=12)
  • Прага (id=7)
  • Замша (id=23)
  ```

### Открытые вопросы
- Нужно ли ограничить максимальное количество образцов в одной заявке?

## Идея 2: Запрос образцов по категории

Клиент выбирает одну или несколько категорий (Костюмные, Рубашечные, Плательные и т.д.) — система автоматически подставляет все ткани из них.

### Варианты UX
- **А.** Кнопка «Запросить всю категорию» прямо на экране списка тканей в категории
- **Б.** Отдельный экран «Заявка на образцы» → выбор категорий чекбоксами → отправить

### Задачи

- [ ] API `api/samples.js` — если передан `category_ids[]`, делает SELECT всех тканей из категорий и разворачивает в items
- [ ] Frontend — кнопка «Запросить все образцы категории» на экране категории
- [ ] Frontend — экран выбора нескольких категорий с чекбоксами
- [ ] Telegram-уведомление — формат для категориального запроса:
  ```
  📦 Заявка на образцы #43 [по категориям]
  👤 Мария (@masha)
  Категории: Костюмные, Рубашечные
  Ткани (15 позиций): ...
  ```

### Открытые вопросы
- При запросе по категории — показывать клиенту список тканей до отправки или отправлять сразу?
- Добавлять ли возможность исключить отдельные ткани из категориального запроса?
